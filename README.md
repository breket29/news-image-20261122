A program that sums up the world news of Sunday, 22 November 2026 in one newspaper-style image: the COP31 climate talks nearing a deal after running into overtime, Australia's AUKUS row with the US budget office, the FBI's crime-database hack, and Mexico's capture of cartel boss "El Chapo Isidro". It validates the embedded poster PNG and writes it to /output/entry.png.

## Run it

```sh
python3 main.py
```

The poster itself is drawn by `draw_poster.py` (PIL) and embedded in `main.py` as base64.
